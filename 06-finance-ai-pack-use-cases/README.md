# Finance AI Pack — Use Cases

These are practical finance automation use cases supported by, or naturally extending from, the Finance AI Pack.

The purpose of this section is to show how the core Finance AI Pack can be applied to real finance operations without presenting every use case as a separate standalone code repository.

## Core repository

https://github.com/Chezhira/finance-ai-pack

## 1. VAT / EFD / TRA Control Monitor

A Tanzania-focused control workflow for reconciling ERP tax data, VAT return figures, EFD documentation, and exception reporting.

Finance AI Pack already supports VAT pack concepts, VAT exception registers, VAT monthly summaries, and HTML VAT reporting.

## 2. Intercompany / Ledger Reconciliation

A use case for matching related-party balances, ledger entries, internal transfers, recharges, and entity-to-entity exceptions.

This fits naturally under ledger reconciliation and month-end close controls.

## 3. Audit Evidence Pack Generator

A use case for packaging close evidence, reconciliation outputs, exception registers, VAT reports, and sign-off schedules into audit-ready support.

This fits naturally under outputs, controls, and month-end gating.

## 4. Finance Dashboards & KPI Pack

A use case for turning finance outputs into decision-ready reporting, management dashboards, board packs, and KPI commentary.

This fits naturally with generated HTML reports, CSV/XLSX outputs, and month-end reporting packs.

## 5. Bank Reconciliation

A core finance control workflow for reconciling bank data, ERP records, unmatched lines, and exception categories.

Finance AI Pack already includes bank reconciliation concepts and generated outputs.

## 6. Month-End Gating

A close-control workflow that summarizes whether finance areas are ready for close sign-off based on exception levels and control thresholds.

This connects bank reconciliation, VAT checks, ledger checks, and reporting readiness into a single close-status view.

## Why these are grouped here

These use cases are not separate standalone repos yet. They are better presented as practical applications of Finance AI Pack.

This keeps the portfolio honest, cleaner, and easier for reviewers to understand.
