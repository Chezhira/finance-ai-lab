# VAT / EFD / TRA Control Monitor

A Tanzania-focused finance control concept for reconciling ERP revenue, VAT treatment, EFD receipts, and tax reporting exceptions.

## Business problem

Finance teams operating in Tanzania often face control risk where accounting records, VAT returns, EFD receipts, and tax declarations do not perfectly align.

Common issues include:

- invoices raised without matching EFD documentation
- EFD receipts issued but not properly reflected in ERP
- export sales needing correct VAT treatment
- intercompany charges needing proper support
- VAT return figures not tying back to accounting records
- manual reconciliations prepared only when audit pressure arises

## What the monitor would do

- compare ERP revenue to EFD records
- compare VAT return figures to ERP tax accounts
- flag missing EFD references
- flag mismatched VAT treatment
- identify export and zero-rated transaction exceptions
- produce a monthly VAT/EFD control report
- create an audit-ready exception log
