# Odoo 19 MCP Server

This project explores how Odoo finance and operational data can be exposed through a structured server layer for AI-assisted workflows, automation, and system interaction.

## Business problem

Finance teams using ERP systems often need faster ways to query, validate, reconcile, and explain data across accounting, inventory, sales, purchases, and operational workflows.

Traditional ERP reporting can be slow or rigid, while AI tools need safe, structured access to business data before they can support finance teams reliably.
